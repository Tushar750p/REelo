# REelo Roadmap

## Phase 1 — MVP
- Vertical For You feed
- Video upload
- Profiles, follows, likes, comments, shares
- API + persistent database
- Authentication

## Phase 2 — AI
- Recommendation ranking model
- Multimodal video understanding
- Auto captions and hashtags
- Semantic search
- Automated safety moderation
- Creator AI assistant

## Phase 3 — Scale & Monetization
- HLS transcoding and CDN
- Notifications and realtime messaging
- Live streaming
- Creator payouts and virtual gifts
- Ads and brand marketplace
- Analytics and fraud/bot detection

## Principle
Build privacy, safety, copyright handling, rate limits and observability into every phase. Never ship an AI safety heuristic as if it were a production moderation system.
