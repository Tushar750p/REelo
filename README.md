# REelo 🚀

AI-first short-video social platform.

## Vision
REelo is designed as a modern short-video platform with personalized feeds, creator tools, AI-powered discovery, moderation, and future monetization.

## Planned Stack
- Frontend: Flutter
- Backend: FastAPI / Python
- Database: PostgreSQL
- Cache: Redis
- Video processing: FFmpeg + HLS
- AI: Python / open-source ML models
- Deployment: Docker + cloud-ready services

## Project Status
🚧 Initial foundation — development starting.

## Planned Modules
- Authentication
- Vertical video feed
- Video upload and processing
- Likes, comments, shares, follows
- Profiles and notifications
- AI recommendations
- AI captions and hashtags
- AI content moderation
- Search and discovery
- Creator analytics
- Admin dashboard
- Monetization infrastructure
